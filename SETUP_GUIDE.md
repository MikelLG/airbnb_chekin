# SETUP_GUIDE — Anika's House Check-in Portal

## Architecture

Single-page HTML app (`index.html`) deployed to GitHub Pages via GitHub Actions.  
Secrets are injected at build time by the workflow; never committed to the repo.

### Build & deploy
- Push to `main` → `.github/workflows/deploy.yml` injects secrets and publishes to GitHub Pages.
- Local dev: `npm run dev` reads `.env` and writes `local-test.html`; open with Live Server (port 5500).

### Secrets required (GitHub → Settings → Secrets)
| Secret | Purpose |
|--------|---------|
| `ANTHROPIC_API_KEY` | Claude Vision for document OCR |
| `ICAL_URL` / `ICAL_URL_2` | Airbnb iCal feeds (room 1, room 2) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | Push notification of .txt file |
| `GH_DISPATCH_PAT` | Triggers `upload_mossos.yml` workflow |

## Language selector

Google Translate is used for translations. A custom `<select>` in the header replaces the default GT widget (which rendered off-screen on mobile).

**Supported languages:** Español · English · Français · Italiano · Deutsch · 中文  
**How to add a language:** add an `<option value="xx">Name</option>` to `#lang-sel` (use BCP-47 code, e.g. `pt` for Portuguese) and add it to `includedLanguages` in `googleTranslateElementInit()`.

Switching back to Español clears the `googtrans` cookie and reloads the page (standard Google Translate restore behaviour).

## Form validation rules (Step 3)

All validation lives in `validateStep3()`. Rules fire top-to-bottom; first failure shows the red error banner (which scrolls into view automatically) and returns false.

| Field | Required | Condition |
|-------|----------|-----------|
| Número documento | yes | always |
| Primer apellido + Nombre | yes | always |
| Formato documento | yes | see Document types below |
| Sexo | yes | always |
| Fecha nacimiento | yes | always |
| Fecha expedición | yes | always |
| Fecha caducidad | yes | must be in the future |
| Fecha entrada / salida / Nº reserva | yes | always |
| Teléfono / Email | yes | labelled "padre/madre" for babies |
| Dirección + Código postal | yes | always |
| **Provincia (INE)** | **yes, only if país = España** | toggled dynamically |
| Localidad | yes, only if país ≠ España | toggled dynamically |
| Declaración de veracidad | yes | checkbox must be checked; turns red if not |

The `*` marker on **Provincia** is hidden automatically when a non-Spanish address is selected (country field or nationality triggers `togglePostalFields()`).

## Document types

| Code | Label | Format | Notes |
|------|-------|--------|-------|
| D | DNI / NIF (solo español) | 8 dígitos + letra | If format fails, error suggests switching to "Otro" |
| N | NIE | X/Y/Z + 7 dígitos + letra | |
| P | Pasaporte | 5–20 alfanumérico | |
| O | Otro (documento extranjero) | 3–30 cualquier carácter | Use for EU ID cards, foreign IDs |

**Changing nationality** (f-nac) now automatically updates which address section is shown (Spain vs non-Spain), preventing users from accidentally typing a city name into the 6-character-limited municipio INE field.

## Check-in / check-out times

Default times in the form:  
- Entrada: **16:00**  
- Salida: **12:00**  

These are written to the Mossos .txt file as `1600` / `1200`. If the Airbnb iCal provides explicit times they override the defaults.

## Mossos .txt file format

Generated by `readCurrentGuest()` + `generateFile()`. Fields are `|`-delimited. All text is uppercased and stripped of diacritics/non-ASCII by `normalizeAscii()` at download time.

Key field positions (0-indexed):
```
0   always "2"
1   num_doc (DNI only)
2   num_pasaport (non-DNI)
3   tipus_doc  (D/P/N/O)
4   data_exp   (YYYYMMDD)
5   cognom1
6   cognom2
7   nom
8   sexe  (M/F/O)
9   data_naix  (YYYYMMDD)
10  nacionalitat  (ISO-3)
11  data_entrada  (YYYYMMDD)
12  hora_entrada  (HHmm)
13  data_sortida  (YYYYMMDD)
14  hora_sortida  (HHmm)
15  data_contracte
16  tipus_contracte  (R=futura, C=pasada)
17  num_contracte  (Airbnb code)
18  num_viatgers
19  always "1"
20  menors  (S/N)
21  always "PLATF"
22  tel  (digits only, max 20)
23  empty
24  correu
25  num_suport  (DNI support number)
26  direccion
27  provincia  (INE 2-digit, Spain only)
28  municipio  (INE 6-digit, Spain only)
29  localitat  (non-Spain)
30  pais_residencia  (ISO-3)
31  codi_postal
```
